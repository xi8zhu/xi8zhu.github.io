普通 Markdown 可以直接写出 **加粗文字**、*斜体文字*、`行内代码` 和 [外部链接](https://astro.build/)。

- <span class="text-blue">蓝色文字适合标记概念或结论。</span>
- <span class="text-red">红色文字只用于风险、限制或需要格外注意的地方。</span>

## 4. 数学公式

### 4.1 行内公式

推荐模型可以写作 $\hat{y}_{u,i}=f_\theta(x_u,x_i,c)$，其中 $u$ 表示用户，$i$ 表示物品，$c$ 表示上下文。

### 4.2 独立公式

如果我们同时考虑即时反馈和长期价值，可以写出一个折扣回报：

$$
G_t = \sum_{k=0}^{\infty}\gamma^k r_{t+k}, \qquad 0 \leq \gamma < 1.
$$

训练目标可以由即时损失与长期价值误差共同构成：

$$
\mathcal{L}(\theta)
= \underbrace{\mathcal{L}_{\mathrm{rec}}(\theta)}_{\text{即时推荐质量}}
+ \lambda\,\underbrace{\mathbb{E}\left[(V_\theta(s_t)-G_t)^2\right]}_{\text{长期价值误差}}.
$$

公式由 KaTeX 在构建阶段渲染，因此页面加载快，也不依赖访问者浏览器临时计算。

## 5. 代码高亮

```python
def discounted_return(rewards, gamma=0.95):
    """从后向前计算每一步的折扣回报。"""
    value = 0.0
    returns = []
    for reward in reversed(rewards):
        value = reward + gamma * value
        returns.append(value)
    return list(reversed(returns))
```
